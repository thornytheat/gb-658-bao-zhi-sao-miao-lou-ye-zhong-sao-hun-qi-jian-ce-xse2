# 数据字典

- run_id：规则版本与输入 SHA-256 前 12 位组成的稳定批次标识。
- line_no：从 1 开始的物理来源行号，不因隔离或排序改变。
- business_key：本项目声明的业务唯一键，始终按字符串存储。
- reason_code：隔离原因的稳定英文编码。
- accepted：进入业务计算的记录数。
- quarantined：保留证据但不参与业务计算的记录数。
- 数值：金额、税额、用量和权重使用 Decimal；对外序列化为字符串。
- 时间：存储为带偏移的 ISO 8601，分桶使用半开区间。
- 空值：缺失键、空串和业务哨兵分别记录。
- 幂等：完整输入字节与规则版本相同则复用 run_id，不新增结果。
- statement_id：站点、账期与规范化输入摘要组成的稳定结算单标识，同输入复用。
- version：结算单乐观锁版本，签收与每次更正登记时递增，过期版本被拒绝。
- signed_amount：签收时冻结的应付金额，之后不再修改，是付款凭据。
- adjustment_id：由结算单、基准版本、原因与更正内容摘要组成的幂等调整标识，重试复用不重复补扣。
- PENDING/POSTED：补扣差额的两段落账状态；中断残留的 PENDING 在回读或下次更正时续传落账。
- decision：ACCEPTED 计费，HELD 未裁决暂挂，DUPLICATE 重复扫描不计费，REJECTED/SUPERSEDED 不计费。
